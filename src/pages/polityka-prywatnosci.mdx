### 4.3 Po co przetwarzamy te dane

Dane z kont reklamowych służą do tego, żeby:

- pokazać użytkownikowi raporty kosztów i wyników kampanii jego klientów;
- porównać wyniki kampanii z oceną leadów przez handlowca (koszt zakwalifikowanego leada);
- wysyłać codzienny skrót kampanii e-mailem i, jeśli użytkownik go włączy, na wskazany kanał Slack;
- wykonać w koncie reklamowym ograniczone działania, **wyłącznie na wyraźne polecenie użytkownika** (w rozmowie z asystentem AI albo kliknięciem w panelu): zmienić budżet dzienny kampanii (wzrost najwyżej o 20% w ciągu 24 godzin), wstrzymać kampanię, zestaw reklam albo reklamę, utworzyć nową kampanię jako wstrzymany szkic, a w Meta zmienić teksty reklamy, która się nie wyświetla. Pełny katalog i ograniczenia opisuje [Regulamin](/regulamin), § 7. Integrator nie uruchamia, nie wznawia i nie usuwa kampanii. Każde takie działanie trafia do dziennika dostępnego dla użytkownika;
- pokazywać alerty ochrony budżetu: codziennie porównujemy wydatki zestawów reklam i kampanii z regułą ustawioną przez użytkownika. Alert jest tylko propozycją, a wstrzymanie wymaga kliknięcia człowieka.

- Nie używamy danych z Meta ani Google do trenowania modeli sztucznej inteligencji, ani własnych, ani cudzych.
- Nie łączymy danych jednego klienta z danymi innych klientów.

Dane trafiają do modelu językowego tylko w dwóch sytuacjach:

1. **Codzienny skrót kampanii.** Wyniki kampanii (nazwy kampanii i reklam, koszty, wskaźniki i ich odchylenia) przekazujemy usłudze Gemini API firmy Google, która pisze z nich opis słowny. W skrócie oznaczamy go jako wygenerowany przez AI. Nie przekazujemy danych osobowych z leadów. Korzystamy z płatnej wersji usługi, w której Google nie używa treści zapytań do trenowania ani ulepszania swoich modeli. Skrót można wyłączyć w panelu (System → Powiadomienia).
2. **Asystent AI wybrany przez użytkownika.** Gdy użytkownik sam podłączy model językowy do Integratora przez protokół MCP, model dostaje dane, o które zapyta w imieniu użytkownika. Dostawca modelu przetwarza je wtedy na warunkach umowy zawartej przez użytkownika.

**Google:** Korzystanie przez Integrator z informacji otrzymanych z interfejsów API Google i przekazywanie ich do innych aplikacji jest zgodne z [Zasadami dotyczącymi danych użytkownika w usługach API Google](https://developers.google.com/terms/api-services-user-data-policy), w tym z wymogami ograniczonego użytkowania (Limited Use).

### 4.8 Google user data: sharing, transfer and disclosure (English)

This section describes how Integrator handles data received from Google APIs (Google user data).

**Data we access.** With the scope `https://www.googleapis.com/auth/adwords` Integrator accesses only the Google Ads accounts that the user selects after signing in with Google: account and campaign names, ad groups, ads and asset groups (ad texts and image addresses), keywords, daily performance metrics (impressions, clicks, cost, conversions), conversion action names, and campaign budgets and statuses.

**How we use it.** To show reports to the user and, only at the user's explicit request, to change a campaign's daily budget (at most +20% within 24 hours), pause a campaign or create a new campaign as a paused draft. Integrator never enables campaigns. If the user sets a budget protection rule, Integrator compares daily campaign costs with that rule and shows an alert in the dashboard; a campaign is paused only when the user clicks the button in the alert.

**With whom we share, transfer or disclose Google user data.** We do not sell Google user data and we do not share it with anyone for advertising, marketing or profiling. Google user data is disclosed only to:

- the user who connected the Google Ads account and the members of the same workspace in Integrator whom that user invited;
- our service providers, who process it on our behalf and only to run Integrator, under data processing agreements: Hetzner Online GmbH (application server, Germany), Supabase (database, Ireland), Cloudflare (secure connection to our server and storage of raw API responses), Google Cloud (encryption keys in Cloud KMS; the Gemini API receives campaign names and metrics to write the text of the daily summary, on a paid tier that does not use the data to train models), Resend (sending the daily summary e-mail) and Slack (only if the user connects their own Slack channel);
- the AI assistant that the user chooses to connect to Integrator through MCP (for example Claude by Anthropic): only the data the assistant requests on the user's behalf, processed under the user's own agreement with that provider;
- public authorities, when we are required to do so by law.

None of these recipients may use Google user data for advertising or to train artificial intelligence models.

**Limited Use.** Integrator's use and transfer to any other app of information received from Google APIs will adhere to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

**Retention and deletion.** Campaign data is kept for up to 400 days and access tokens until the account is disconnected. The user can revoke access at any time at [myaccount.google.com/connections](https://myaccount.google.com/connections) and can request deletion of all data by writing to [kontakt@serwer-side.pl](mailto:kontakt@serwer-side.pl); we delete it within 30 days (see section 8).

W ciągu 30 dni usuniemy tokeny dostępu, dane kampanii, leady i kopie surowe i potwierdzimy to mailowo.

Jeśli wniosek składa osoba, której dane są w leadzie, przekażemy go administratorowi (agencji albo reklamodawcy) i usuniemy dane na jego polecenie.
